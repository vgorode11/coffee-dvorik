Современный сайт кофейни "Кофейный дворик" в г. Владикавказ с полным меню, AI-помощником по выбору напитков и системой отзывов.

## 🌟 Особенности сайта

### 🎨 Современный дизайн
- Чистый, минималистичный дизайн в приглушенных зеленых тонах
- Полная адаптивность для всех устройств (десктоп, планшет, мобильные)
- Плавные анимации и переходы

### ☕ Полное меню кофейни
- **Классический кофе**: Эспрессо, Американо, Латте, Капучино и др.
- **Раф-кофе**: Классический, Малиновый, Фисташковый, Черничный
- **Холодные напитки**: Холодный Раф, Латте, Американо
- **Чай**: Ассам, Сенча, Горный, Жасмин, Фруктовые чаи
- **Фреши и лимонады**: Апельсин, Грейпфрут, Малиновый грейп
- **Закуски и десерты**: Боулы, сэндвичи, чизкейк, медовик

### 🤖 AI-Кофейный помощник
- Интеллектуальная система подбора напитков
- 3 шага для персонализированной рекомендации:
  1. **Настроение** (бодрое, расслабленное, творческое, сосредоточенное)
  2. **Время суток** (утро, день, вечер)
  3. **Предпочтения** (классика, сладкое, холодное, полезное)
- Показывает рекомендованный напиток с объяснением выбора

### 📝 Система отзывов
- Отправка отзывов напрямую в Telegram бот
- Уведомления об успешной отправке
- Сохранение отзывов в localStorage (резервная копия)
- Оценка от 1 до 5 звезд

### 📱 Функциональность
- **Слайдер с автопрокруткой** - демонстрация кофейни
- **Фильтрация меню** по категориям
- **Карточки продуктов** с детальной информацией
- **Контакты** с адресом и часами работы
- **Плавная прокрутка** по странице

## 🚀 Как развернуть на GitHub Pages

1. **Создайте репозиторий** на GitHub
2. **Загрузите файлы**:
   - `index.html` (главная страница)
   - Изображения (1.jpg, 2.jpg, 3.jpg и т.д.)
   - `README.md` (этот файл)
3. **Включите GitHub Pages**:
   - Зайдите в Settings → Pages
   - В разделе "Source" выберите "main" branch
   - Нажмите "Save"
4. **Сайт будет доступен** по адресу:
   `https://ваш-username.github.io/название-репозитория/`

3. **Узнать ID чата** (можно через @userinfobot)
